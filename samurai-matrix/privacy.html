Samurai Matrix — Privacy Policy

Last updated: November 8, 2026

Overview

Samurai Matrix is a Chrome extension featuring animated Matrix rain, customizable neon colors, glitch effects, and optional Google Search styling.

Information Accessed

Theme preferences and user-created shortcuts are saved locally using Chrome storage.

The extension accesses Chrome bookmarks and recent download information to display them inside the New Tab interface.

Optional Google Search styling changes the appearance of supported search pages.

Data Collection and Sharing

Samurai Matrix does not transmit bookmarks, downloads, search queries, or theme preferences to developer-operated servers.

It does not use analytics or advertising trackers and does not sell personal information.

User Control

Users can customize settings, remove saved shortcuts, and uninstall the extension.
